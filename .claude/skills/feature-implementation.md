## Quand MOI et pas un autre
-MOI : une feature à implémenter, fichiers dans src/
-brainstorming : si le besoin n'est pas encore défini
-write-tests : si le code existe déjà et qu'il manque des tests

## Protocole
1.Lire la spec Gherkin dans specifications/
2.Vérifier les composants existants avant de créer
3.Implémenter en suivant la structure : types → logique → interface
4.Écrire les tests en même temps (pas après)
5.Lancer les vérifications locales avant de déclarer terminé

## Conditions de sortie
-[ ] Tests écrits et verts
-[ ] Lint propre
-[ ] Pas de TODO laissé sans ticket
