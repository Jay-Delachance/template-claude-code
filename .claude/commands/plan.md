# .claude/commands/plan.md

Entre en mode planification. N'écris AUCUNE ligne de code pendant cette 
phase.

Pour cette tâche, tu dois :
1.Explorer le problème et lire les fichiers concernés
2.Poser des questions de clarification si le périmètre n'est pas clair
3.Proposer une décomposition en tâches avec dépendances
4.Produire un fichier plans/YYYY-MM-DD-[sujet].md

Format du plan :
# Plan · YYYY-MM-DD · [sujet]
## T1 · [description] (~Xh)
## T2 · [description] (dépend de T1)
## T3 · [description] (dépend de T1)

Attendre la validation humaine avant de commencer T1.
